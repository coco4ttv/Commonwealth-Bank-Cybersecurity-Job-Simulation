# Commonwealth Bank Cybersecurity Job Simulation

This repository records my work from the **Commonwealth Bank Introduction to Cybersecurity Job Simulation** completed through Forage. It was a guided virtual experience, not paid employment or a real client engagement.

## Task areas

My simulation work covered:

- **Data analysis:** working with Splunk dashboards to look for fraud patterns.
- **Incident response:** considering how security events should be investigated and handled.
- **Security awareness:** preparing a password-awareness infographic aligned with Australian Cyber Security Centre (ACSC) guidance.
- **Web application security:** completing a guided security assessment task.

These are summaries of the simulation tasks, not claims that I investigated real bank systems or detected actual fraud.
